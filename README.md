# Swipe 2027

Les propositions des candidats à la présidentielle 2027, une par une, façon appli de rencontre : critiques sourcées, coût, votes à l'Assemblée, condamnations, chat IA.

- `site/` : l'application (site + fonctions IA Vercel + schéma Supabase). Le déploiement est expliqué dans `site/README.md`.
- `data/` : les données sources (programmes, fiches sourcées, scrutins de l'Assemblée, condamnations).
- `CONCEPT.md` : l'idée de départ.
- `ROADMAP_MAXIME.md` : les notes de Maxime sur la suite (à discuter).

Reconstruire le site après une modification des données : `cd site && python3 build.py`.
